# Spine Harness — macOS package

Start with [the macOS quick start](docs/portable/macos/QUICKSTART.md) to run **one issue through four workflows**: Spine + PKG, Spine + integrated OpenSpec + PKG, standalone OpenSpec, and Spec Kit. It covers package verification, required inputs, a Codex app prompt, terminal commands, and where to find results.

For more detail, use the [four-arm qualification guide](docs/MATRIX_QUICKSTART.md). To reproduce the older two-arm Jira protocol, use the [historical guide](docs/portable/macos/TWO_ARM_JIRA.md). The [33-scenario reference study](docs/QUICKSTART.md) is a later, larger run.

Building or opening this package makes no model calls. A four-arm run does; review the issue, baseline, and independent checks before authorizing it.
